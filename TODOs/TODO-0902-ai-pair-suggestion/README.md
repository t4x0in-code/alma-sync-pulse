# TODO-0902 — AI-подсказки совместимых пар

**Приоритет:** P4 (roadmap)
**Статус:** open

## Контекст
Ручной matching занимает время Тони. AI может предлагать совместимые пары на основе истории, возраста, уровня, частоты совместных посещений.

## Задача
1. Сигналы для модели:
   - возраст (±5 лет — приоритет);
   - level совпадает / соседний;
   - частота совместных подтверждённых пар в прошлом;
   - комментарии в заявке (через embedding на Lovable AI Gateway);
   - роль (Leader/Follower) и предпочтения по росту (опционально).
2. Score 0–100 для каждой возможной пары.
3. В `/tony-admin` — секция **Vorgeschlagene Paare** с топ-10 + кнопкой «применить».
4. В Telegram — команда `/suggest` для конкретного solo-студента.
5. Privacy: opt-out, без хранения сырых embedding'ов вне tenant'а.

## Acceptance criteria
- [ ] Подсказки появляются при ≥ 5 solo студентов.
- [ ] Тони принимает рекомендацию одним тапом.
- [ ] Качество подсказок измеряется (acceptance rate).
