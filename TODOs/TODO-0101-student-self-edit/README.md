# TODO-0101 — Самостоятельное редактирование заявки студентом (magic-link)

**Приоритет:** P1
**Статус:** open

## Контекст

Сейчас заявку может изменить только админ. Студент не может поправить опечатку, обновить фото, отменить запись или сменить роль (Leader/Follower).

## Задача

1. После создания заявки бот отправляет студенту **magic-link** `https://app/.../enroll/:token` (token = 30 дней, one-per-enrollment).
   - Если контакт `telegram` — DM от бота.
   - Если `email` — через SMTP / Resend / SendGrid.
   - Если `phone` — отображается на странице успеха для копирования.
2. По magic-link открывается форма с предзаполненными полями + кнопки **Speichern** / **Abmelden**.
3. Все изменения логируются и пушатся Тони в Telegram.

## Acceptance criteria

- [ ] Студент может изменить имя, возраст, роль, комментарий, фото.
- [ ] Студент может отменить участие → место освобождается, пара (если была) распадается.
- [ ] Token истекает через 30 дней или после Abmeldung.
