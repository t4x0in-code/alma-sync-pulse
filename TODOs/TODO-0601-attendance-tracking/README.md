# TODO-0601 — Учёт фактической посещаемости

**Приоритет:** P3
**Статус:** open

## Контекст

Запись ≠ посещение. Тони нужен быстрый чек-ин на месте — для статистики и списания с абонементов (TODO-0600).

## Задача

1. На `/tony-admin` — режим **Check-in** (большие чекбоксы рядом с именами, mobile-friendly).
2. В Telegram-боте `/checkin` — список студентов с inline-кнопками ✅/❌.
3. QR-код студента (генерируется в `/enroll/:token`); Тони сканирует камерой телефона → автоматический check-in.
4. После занятия — списание 1 кредита с абонемента, фиксация в `attendance_log`.
5. No-show после 3 раз → email-нудж от бота.

## Acceptance criteria

- [ ] Check-in 20 студентов занимает ≤ 60 секунд.
- [ ] История посещений доступна в профиле студента.
