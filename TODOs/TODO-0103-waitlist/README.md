# TODO-0103 — Лист ожидания при заполненном курсе

**Приоритет:** P1
**Статус:** open

## Контекст

Когда курс полон, форма должна не отказывать, а ставить в waitlist с автопромоушеном при освобождении места.

## Задача

1. При `enrollments_count ≥ capacity` форма принимает заявку со статусом `waitlist`, отдельно по полу (важно для баланса M/F).
2. При освобождении места (Abmeldung, разрыв пары) — автопромоушен **первого подходящего по полу** студента из листа ожидания. Уведомление через Telegram/email.
3. Студент видит свою позицию: «3-я в очереди (Follower)».
4. Тони в `/tony-admin` и через `/list_waitlist` в боте видит весь лист с возможностью ручного промоушена.

## Acceptance criteria

- [ ] Запись не отклоняется, когда курс полон.
- [ ] При освобождении места waitlist автоматически продвигается с учётом M/F баланса.
- [ ] Студент получает уведомление о попадании на курс.
