# TODO-0602 — История посещений и профиль ученика

**Приоритет:** P3
**Статус:** open

## Контекст
Студент должен видеть свою историю занятий, текущих партнёров, баланс абонемента — это повышает retention.

## Задача
1. Страница `/me` (доступ через magic-link или Telegram login).
2. Секции:
   - **Nächste Stunden** — будущие записи + кнопки отмены.
   - **Verlauf** — посещённые занятия, кто был партнёром.
   - **Mein Profil** — фото, возраст, роль (с возможностью смены), контакт.
   - **Guthaben** — баланс абонемента + история транзакций.
   - **Stammpartner** — кнопка «постоянная пара с …» (TODO-0102 + reserved pairs).
3. Privacy: студент может скрыть фото от других, скрыть возраст.

## Acceptance criteria
- [ ] Профиль отображает корректные данные за всё время.
- [ ] Privacy-настройки соблюдаются на всех экранах.
