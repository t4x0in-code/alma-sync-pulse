# TODO-0102 — Полноценный двухсторонний flow подтверждения пары

**Приоритет:** P1
**Статус:** open

## Контекст

Pair matching реализован: proposed → confirmed. Но второй стороне сейчас неоткуда подтвердить — это делает только админ.

## Задача

1. При создании `proposed pair` второй участник получает уведомление (Telegram DM / email):
   > «Maria (28) предлагает танцевать с тобой в четверг. Подтвердить?»
   > с кнопками **Ja** / **Nein** / **Profil ansehen** (фото + комментарий + возраст).
2. На веб-странице `/enroll/:token` (см. TODO-0101) появляется секция **Eingehende Anfragen** со списком кандидатов и теми же действиями.
3. Подтверждение / отказ синхронно отражаются и в боте, и в веб-аппе (через Realtime — TODO-0100).
4. Можно отправлять свою proposal другому solo-участнику (с фильтром по возрасту ±N лет).
5. Защита от спама: ≤ 3 активных proposals одновременно от одного человека.

## Acceptance criteria

- [ ] Студент видит входящие предложения и подтверждает их без участия Тони.
- [ ] Confirmed pair блокирует слот, отказ — освобождает.
- [ ] История proposals хранится для аналитики.
